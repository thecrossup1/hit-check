⚙ Connection settings

Data syncs through a GitHub Gist — works from any device once connected. Needs a classic token with the gist scope (fine-grained tokens don't support Gists yet).

This token lives only in this browser's storage and can read/write all of your Gists, not just this one — avoid saving it on a shared or public device, and hit Disconnect when you're done on one.

The Gist is the real cross-device database — this is just an extra offline copy.

📦 Add data (ripodd / WaxMetrix)
